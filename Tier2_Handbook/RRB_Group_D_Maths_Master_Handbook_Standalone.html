📖 1. Concept Overview

What is Trigonometry?

Trigonometry deals with relationships between angles and sides of triangles, especially right-angled triangles.

🎯 What It Means

Study of ratios in right triangles: sin, cos, tan, and their reciprocals

💡 Why It's Used

To find unknown sides or angles when some measurements are given

📍 Where It's Used

Height & distance problems, simplification, value finding

📝 How Examiner Asks

Direct value finding, identity simplification, height-distance applications

sin²θ + cos²θ = 1

1 + tan²θ = sec²θ

1 + cot²θ = cosec²θ

Derived by dividing sin²θ + cos²θ = 1 by sin²θ

🔹 Complementary Angles

sin(90° - θ) = cos θ
cos(90° - θ) = sin θ
tan(90° - θ) = cot θ

When angle becomes (90° - θ), function changes to its complement

🔹 Allied Angles

sin(180° - θ) = sin θ
cos(180° - θ) = -cos θ
tan(180° - θ) = -tan θ
sin(-θ) = -sin θ

🔬 4. Formula Derivations (Step by Step)

Derivation of sin²θ + cos²θ = 1

Step 1: In a right triangle, by Pythagoras theorem:

H² = P² + B²

Step 2: We know sin θ = P/H and cos θ = B/H

Step 3: Square both:

sin²θ = P²/H²
cos²θ = B²/H²

Step 4: Add them:

sin²θ + cos²θ = P²/H² + B²/H² = (P² + B²)/H²

Step 5: From Step 1, P² + B² = H²

∴ sin²θ + cos²θ = H²/H² = 1

✓ Hence Proved: sin²θ + cos²θ = 1

Derivation of 1 + tan²θ = sec²θ

Step 1: Start with fundamental identity:

sin²θ + cos²θ = 1

Step 2: Divide entire equation by cos²θ:

(sin²θ/cos²θ) + (cos²θ/cos²θ) = 1/cos²θ

Step 3: Simplify each term:

tan²θ + 1 = sec²θ

[Since sin θ/cos θ = tan θ and 1/cos θ = sec θ]

✓ Hence Proved: 1 + tan²θ = sec²θ

Variation 1: Direct Value Finding ⭐⭐⭐⭐⭐

Pattern: Given a standard angle, find the value of a trigonometric expression

Keywords: "Find the value", "Evaluate", "Calculate"

🟢 Easy Example

Q: Find the value of sin 30° + cos 60°

Step-by-step:

sin 30° = 1/2 (from table)

cos 60° = 1/2 (from table)

Sum = 1/2 + 1/2 = 1

Answer: 1

⚡ Shortcut: Remember sin 30° = cos 60° = 1/2, so sum is always 1

🟡 Medium Example

Q: Evaluate: (sin 45° × cos 45°) + tan 45°

Step-by-step:

sin 45° = 1/√2

cos 45° = 1/√2

tan 45° = 1

(1/√2 × 1/√2) + 1 = 1/2 + 1 = 3/2

Answer: 3/2 or 1.5

⚡ Shortcut: sin θ × cos θ at 45° = (1/√2)² = 1/2 directly

🔴 Hard Example

Q: If sin θ = 3/5, find the value of (cos θ + cosec θ)

Step-by-step:

Given: sin θ = 3/5 = P/H

So P = 3, H = 5

Using Pythagoras: B = √(H² - P²) = √(25 - 9) = √16 = 4

cos θ = B/H = 4/5

cosec θ = H/P = 5/3

cos θ + cosec θ = 4/5 + 5/3 = (12 + 25)/15 = 37/15

Answer: 37/15

⚡ Shortcut: Remember 3-4-5 triangle. If sin = 3/5, then cos = 4/5 immediately

📝 Exam-Level Example (PYQ Style)

Q: What is the value of sin² 30° + cos² 30°?

Method 1 (Calculation):

sin 30° = 1/2, so sin² 30° = 1/4

cos 30° = √3/2, so cos² 30° = 3/4

Sum = 1/4 + 3/4 = 1

Method 2 (Identity - Instant!):

By identity: sin²θ + cos²θ = 1 for ANY angle θ

Answer: 1 (solve in 3 seconds!)

Variation 2: Identity Simplification ⭐⭐⭐⭐

Pattern: Simplify complex trigonometric expressions using identities

Keywords: "Simplify", "Prove that", "Show that"

🟢 Easy Example

Q: Simplify: (1 - sin²θ)

Using identity: sin²θ + cos²θ = 1

Therefore: 1 - sin²θ = cos²θ

Answer: cos²θ

🟡 Medium Example

Q: Simplify: (sec²θ - 1)(cosec²θ - 1)

Using identities:

sec²θ - 1 = tan²θ

cosec²θ - 1 = cot²θ

Product = tan²θ × cot²θ

Since cot θ = 1/tan θ, we get tan²θ × (1/tan²θ) = 1

Answer: 1

🔴 Hard Example

Q: If x = a sec θ and y = b tan θ, find x²/a² - y²/b²

x/a = sec θ, so x²/a² = sec²θ

y/b = tan θ, so y²/b² = tan²θ

x²/a² - y²/b² = sec²θ - tan²θ

Using identity: sec²θ - tan²θ = 1

Answer: 1

tan 45° = Height/Shadow

1 = Height/10

Height = 10 m

Answer: 10 m

⚡ Shortcut: At 45°, height = shadow length (tan 45° = 1)

🟡 Medium Example

Q: From a point 20 m away from a tower, angle of elevation is 60°. Find height.

tan 60° = Height/Base

√3 = Height/20

Height = 20√3 m

Answer: 20√3 m

🔴 Hard Example

Q: A man observes top of a tower at 30°. After moving 40 m closer, angle becomes 60°. Find tower height.

Let height = h, initial distance = x

From first position: tan 30° = h/x → 1/√3 = h/x → x = h√3

From second position: tan 60° = h/(x-40) → √3 = h/(h√3 - 40)

√3(h√3 - 40) = h

3h - 40√3 = h

2h = 40√3

h = 20√3 m

Answer: 20√3 m

❌ 8. Common Mistakes to Avoid

Mistake 1: Confusing sin and cos values

Wrong: Thinking sin 60° = 1/2

Correct: sin 60° = √3/2, sin 30° = 1/2

Fix: Remember sin increases from 0° to 90°

Mistake 2: Sign errors in quadrants

Wrong: cos(180° - θ) = cos θ

Correct: cos(180° - θ) = -cos θ

Fix: Remember "All Silver Tea Cups" (ASTC) rule

Mistake 3: Forgetting reciprocal relationships

Wrong: cosec θ = 1/sin θ but writing sin θ = 1/cosec θ incorrectly

Fix: Practice: sin ↔ cosec, cos ↔ sec, tan ↔ cot

Mistake 4: Not recognizing standard triangles

Wrong: Calculating sides every time

Fix: Memorize 30-60-90 and 45-45-90 triangle ratios
