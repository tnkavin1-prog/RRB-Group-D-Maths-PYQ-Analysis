## 🧮 Master Formula Handbook

### 1️⃣ PERCENTAGE

| Formula Type | Formula | Memory Trick |
|--------------|---------|--------------|
| Basic | `Percentage = (Part/Whole) × 100` | "Part over Whole, times 100" |
| Increase | `New = Original × (1 + r/100)` | "Add the rate fraction" |
| Decrease | `New = Original × (1 - r/100)` | "Subtract the rate fraction" |
| Successive | `Net% = a + b + (ab/100)` | "Sum plus product over 100" |

**💡 Shortcut Tricks:**
- 10% = Divide by 10
- 20% = Divide by 5
- 25% = Divide by 4
- 33⅓% = Divide by 3
- 50% = Divide by 2
- 75% = Divide by 4, multiply by 3

### 2️⃣ PROFIT & LOSS

| Formula Type | Formula | When to Use |
|--------------|---------|-------------|
| Profit | `Profit = SP - CP` | When SP > CP |
| Loss | `Loss = CP - SP` | When CP > SP |
| Profit % | `Profit% = (Profit/CP) × 100` | Always on CP |
| Loss % | `Loss% = (Loss/CP) × 100` | Always on CP |
| SP from CP | `SP = CP × (100 + Profit%)/100` | Given CP and profit% |
| CP from SP | `CP = SP × 100/(100 + Profit%)` | Given SP and profit% |
| Discount % | `Discount% = (MP - SP)/MP × 100` | Always on MP |

**💡 Quick Calculation Hack:**
```
If CP = 100, Profit% = 20 → SP = 120 (mental math)
If SP = 120, Profit% = 20 → CP = 100 (reverse)
```

### 3️⃣ SIMPLE & COMPOUND INTEREST

| Formula Type | Formula | Application |
|--------------|---------|-------------|
| Simple Interest | `SI = (P × R × T)/100` | Linear growth |
| Amount (SI) | `A = P(1 + RT/100)` | Total after SI |
| Compound Interest | `CI = P(1 + R/100)^T - P` | Exponential growth |
| Amount (CI) | `A = P(1 + R/100)^T` | Total after CI |
| Difference (2 yrs) | `Diff = P(R/100)²` | SI vs CI for 2 years |

**💡 Mental Math Shortcuts:**
- For 1 year: SI = CI (always!)
- For 2 years: Difference = P × (R/100)²
- Rate 10%, 2 years: CI is 21% effective (10 + 10 + 1)

### 5️⃣ TRIGONOMETRY

| Function | Formula | Value Table |
|----------|---------|-------------|
| sin θ | Perpendicular/Hypotenuse | sin 0°=0, sin 30°=½, sin 45°=1/√2, sin 60°=√3/2, sin 90°=1 |
| cos θ | Base/Hypotenuse | cos 0°=1, cos 30°=√3/2, cos 45°=1/√2, cos 60°=½, cos 90°=0 |
| tan θ | Perpendicular/Base | tan 0°=0, tan 30°=1/√3, tan 45°=1, tan 60°=√3, tan 90°=∞ |

**🔑 Core Identities (MUST MEMORIZE):**
```
① sin²θ + cos²θ = 1          ← "The Golden Identity"
② 1 + tan²θ = sec²θ          ← "Tangent-Secant pair"
③ 1 + cot²θ = cosec²θ        ← "Cotangent-Cosecant pair"
```

**💡 Memory Mnemonic:**
> "**S**ome **P**eople **H**ave **C**urly **B**lack **H**air"  
> Sin = P/H, Cos = B/H, Tan = P/B

### 6️⃣ MENSURATION (2D)

| Shape | Area | Perimeter |
|-------|------|-----------|
| Rectangle | `l × b` | `2(l + b)` |
| Square | `side²` | `4 × side` |
| Triangle | `½ × base × height` | `a + b + c` |
| Circle | `πr²` | `2πr` |
| Quadrilateral (diagonals ⊥) | `½ × d₁ × d₂` | Varies |

**🎯 Special Case - Rhombus/Kite:**
When diagonals are perpendicular bisectors:
```
Area = ½ × d₁ × d₂
Given: d₁ = 8 cm, Area = 48 cm²
48 = ½ × 8 × d₂ → d₂ = 12 cm
```

### 7️⃣ MENSURATION (3D)

| Solid | Volume | Total Surface Area |
|-------|--------|-------------------|
| Cube | `side³` | `6 × side²` |
| Cuboid | `l × b × h` | `2(lb + bh + hl)` |
| Cylinder | `πr²h` | `2πr(r + h)` |
| Cone | `⅓πr²h` | `πr(r + l)` where l = slant height |
| Sphere | `4/3 πr³` | `4πr²` |
| Hemisphere | `2/3 πr³` | `3πr²` |

**💡 Cylinder Shortcut:**
```
Curved SA = 2πrh
Total SA = 2πr(r + h) = Curved SA + 2πr²
```

#### Percentage Shortcuts
```
Find 37% of 200 → Think: 37% of 100 = 37, so 37% of 200 = 74
Find 15% of any number → 10% + half of 10%
Example: 15% of 240 = 24 + 12 = 36

Example: 248 × 5 = 124 × 10 = 1240

× 25: Divide by 4, then × 100
Example: 48 × 25 = 12 × 100 = 1200

× 125: Divide by 8, then × 1000
Example: 32 × 125 = 4 × 1000 = 4000

```
Numbers ending in 5: (n5)² = n(n+1) | 25

        65² = 6×7 | 25 = 4225

Near 50: (50+n)² = (25+n) | n²
Example: 53² = (25+3) | 9 = 2809

### 🎯 Exam Hacks by Topic

#### Trigonometry Quick Wins
```
✓ If sin θ = 3/5, then cos θ = 4/5 (Pythagorean triplet 3-4-5)
✓ tan 45° = 1, sin 30° = ½, cos 60° = ½ (memorize these 3)
✓ sin²θ + cos²θ = 1 → Use when one value given, find other
```

#### Number System Speed Rules
```
✓ Divisible by 90? → Check last digit 0 AND sum divisible by 9
✓ Prime check up to 100? → Test divisibility by 2,3,5,7 only
✓ LCM of fractions = LCM(numerators)/HCF(denominators)
```

#### Profit-Loss Lightning
```
✓ If SP of 2 items same, one at x% profit, other at x% loss → Overall LOSS
  Loss% = (x/10)²
  Example: 20% profit on one, 20% loss on other → Loss = 4%

✓ Successive discounts: d₁% and d₂% → Net discount = d₁ + d₂ - (d₁×d₂)/100
```

#### SI-CI Rapid Fire
```
✓ For 2 years: CI - SI = P(R/100)²
✓ For 3 years: CI - SI = P(R/100)²(3 + R/100)
✓ CI for 1st year = SI for 1st year (always!)
```

#### Time-Speed-Distance Express
```
✓ Change in speed, same distance: Time ratio = Inverse of speed ratio
✓ Train crosses pole: Distance = Length of train only
✓ Train crosses platform: Distance = Train length + Platform length
```

## 🎭 Examiner's Tricks Exposed

### 🔮 How Questions Are Designed to Trap You

#### Trick 1: The Close Options
```
Question: Find 15% of 240
Options: A) 36  B) 34  C) 38  D) 35
Trap: Rushing students might calculate 10% = 24, forget to add half (12)
Correct: 24 + 12 = 36
```

#### Trick 2: The Unit Switch
```
Question: Speed in km/hr, distance in meters, time asked in seconds
Trap: Direct formula gives wrong answer
Solution: Convert ALL to same unit system first
```

#### Trick 3: The Almost-Right Formula
```
Question: Successive discounts of 20% and 10%
Wrong approach: 20 + 10 = 30%
Correct: 20 + 10 - (20×10)/100 = 28%
Trap option 30% is always present!
```

#### Trick 4: The Hidden Condition
```
Question: "A five-digit number 761xy is divisible by 90"
Hidden: Must end in 0 (for 10) AND sum divisible by 9
Many students check only one condition
```

#### Trick 5: The Irrelevant Data
```
Question with extra information not needed for solution
Purpose: Waste your time, create confusion
Strategy: Identify what's asked FIRST, then pick relevant data
```
